# BLOCK FEAST（仮）

飲食で抽選券を獲得し、抽選したテトリス型ブロックで最下段の消去を目指す、スマホ向け静的Webアプリです。

## GitHub Pagesで公開

1. GitHubで新しいリポジトリを作成
2. `index.html`、`style.css`、`app.js`をアップロード
3. Settings → Pages
4. Sourceを「Deploy from a branch」
5. Branchを `main` / `(root)` にしてSave
6. 表示されたURLをiPhoneで開く
7. Safariの共有ボタン →「ホーム画面に追加」

## 主な仕様

- 初期盤面作成：5 / 10 / 15 / 20段の積み上がりから通常プレイ
- ゲームオーバー時の盤面を本編へ引き継ぎ
- 飲み物：同じ品でも登録可能
- 食べ物：同一飲食エリア内では重複不可
- エリア変更で食べ物の重複制限をリセット
- 通常抽選：抽選券1枚
- 1種除外抽選：抽選券3枚（通常1枚 + 追加2枚）
- ジョーカー：券を消費するがブロックなし
- エース：好きなブロックを選択
- エース／ジョーカー枚数を設定可能
- 進行状況は端末のlocalStorageに自動保存
